## 六、审核流程

1. 机器人写 2 篇待审草稿 → GitHub Actions 或本地脚本跑完即止
2. 岛主打开审核页（深链见 §七），逐篇看：图、文、来源、`rights_status`
3. 岛主点通过/打回 → 走 `review_daily_learning_v2` RPC（唯一合法审批路径）
4. 通过后**自动发布**：`review_daily_learning_v2` RPC 在同一事务内写审核决定+发布记录（岛主会话执行，权限合法），一次点击即上线
5. **两篇都审**，不抽查 | ✅ 决定
