# 每日一看：岛主已确认的决定

下一位 Agent 必须先读。本文件只记录岛主明确确认、且仍有效的业务决定。

## 2026-10-30：自动入库与正式发布分开

- `validateLearningPackageV2.valid=true` 即可自动写入私有草稿队列。
- `readyForOwnerReview=false`、图片无许可、无法读取、缺图、史实或版本待核都不能成为拒绝私有入库的理由。
- 未核内容必须继续标记 `needs_review/blocked`，不能伪写通过。
- 岛主无需逐次批准私有入库，也无需手工复制 JSON。
- 岛主独占正式发布决定。

## 2026-10-30：未锁定草稿是工作副本

- 同一 `content_id` 下，未批准、未发布、无正式审核决定且处于 `pending_review / awaiting_owner_review` 的草稿原地更新。
- 更新保留 `id`、`source_id`、`version`。
- 已批准、已发布或已有正式审核决定的版本保持不可变；后续修订新增版本。

## 2026-11-04：发布门禁以结构有效和主图为准

- v2 包结构有效并含结构有效的主图时，岛主可主动发布。
- 未核 claims、版权、史实、来源、部署和 blockers 继续展示并进入发布快照，不禁用岛主发布按钮。
- 该规则不授权 Agent 自动批准或发布。

## 2026-11-05：公开文案与审核状态严格分离

- 作品资料和正文不得出现候选、待核、受阻、研究草稿、图片尚待读取等内部流程词。
- 不确定性只放在 claims、quality、human review、图片权利记录和审核界面。
- 清理公开文案不等于核查通过。

## 2026-11-05：图片性能和方向

- 可追溯原图只作研究证据。
- 公开交付必须另生成等比阅读图和轻量首页缩略图。
- manifest 记录阅读图、缩略图、字节数和 SHA256。
- 竖图完整显示并使用 `contain`；不得为卡片擅自裁掉人物或作品边界。
- 除非审核包明确记录裁切，不得裁切作品内容。

## 长期边界

- 不读取私人反馈。
- 不使用 Gemini 或其他外部生成模型。
- 不自动批准、发布或修改历史快照。
- 浏览器验证由岛主手动完成；Agent 只做代码、数据和构建验证。
- 有新图片、manifest、规范或必要代码时，自动化可以在全部校验通过后作严格限定的提交并推送主分支；部署不代表文章发布。
