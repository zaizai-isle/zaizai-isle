# 每日一看：已拒绝或废止的做法

下一位 Agent 不应再次建议或执行以下做法。

- 要求岛主逐次批准私有草稿入库。
- 要求岛主手工复制、粘贴或导入 JSON。
- 因 `readyForOwnerReview=false`、版权待核、图片不可达或史实待核而拒绝结构有效的私有草稿入库。
- 为了入库把未知字段改成 `verified/passed`。
- 为补图、补证或改文案给同一未锁定草稿增加版本。
- 用旧本地研究文件覆盖数据库中更新的补图稿。
- 把过程记录、备份或旧 blocked 包误作新的数据库内容版本。
- UPDATE 发生并发失败后改为 INSERT，从而制造重复草稿。
- 自动调用审核、批准或发布接口。
- 把未部署的本地图片写成“已部署”或把浏览器未验证写成“已验证”。
- 把许可核查等同于文件可达性，把文件可达性等同于作品匹配。
- 从作品物理尺寸、搜索缩略图或同名作品猜图片像素尺寸。
- 混用同名作品、同馆部件记录、相似器物或不同版本的图片、尺寸和说明。
- 在读者文案中写待核、受阻、研究草稿等内部流程说明。
- 首页直接加载原始大图或详情图。
- 用 `cover` 截掉竖幅人物、作品上下边界，或无记录地裁切作品。
- 把原始大图、临时研究、密钥或工作区其他修改夹带进自动化提交。
- 强推、改写历史或在远端分叉时继续推送。
- 使用 Gemini 或其他外部生成模型替代研究和写作。
- 让 Agent 执行浏览器页面验证。
