## 1. 隐喻模型（作者确认）

```
人生护照 = 一个本子（整体身份：封面、护照号、主人昵称）
  └─ 盒子 = 主题分类（12 个既有主题 + 新默认盒「无题」= 13 个）
       └─ 卡片 = 印章记录（唯一必填：一句话正文）
            └─ 模板 = 卡片皮肤（6 套，与主题完全解耦，独立可选）
```

**核心原则：**
1. **主题是主题，模板是模板**——互不影响，各自独立选择。
2. **输入压力最小化**——必填只剩一句话；其余全部自动、默认或记忆上次。
3. **归档零决策**——没选盒子就落「无题」盒，不阻断流程。

## 2. 三幕流程

### 第一幕 · 书桌（`/achievement`，保持输入页定位）
- 桌面一张空白卡，**唯一必填 = 一句话正文**；邮戳自动盖今天（点击可改）。
- `[+ 贴一张照片]` 可选。
- `不知道写什么？→ 灵感库`：辅助入口（非主入口），点一条 96 预设成就 = 卡片印好标题/格言骨架，可只补一句话或不补。
- **盒子排**（13 只换装鲸头鹳，点选归档目标）：12 主题 + 「无题」；正文关键词推断的主题盒高亮为推荐；不点 → 落「无题」。
- **模板排**（6 枚迷你卡横滑，独立于盒子）：默认沿用上次使用的模板（localStorage 记忆），初始默认 `envelope`。
- 风格/纹理等高级选项默认折叠。

### 第二幕 · 归档
- 点盒子 = 归档完成，盖章动画 + 文案"已放入「远行与突破」· 第 3 张"；未选则"已放入「无题」"。

### 第三幕 · 护照页（`/achievement/passport` = 盒子打开后的效果）
- **单页盒架**：本子跨页上摆 13 个打开的盒子；空盒半透明弱化排后；盒口露出该主题最近卡片边缘。
- 点盒子 → 该主题卡片扇形展开浏览；点卡片 → 现有海报弹层。
- 保留现有功能：云/本地状态、删除确认、护照号——只换皮不减功能。

## 5. 数据模型变更

```
StampDraft / Stamp 新增: templateId: TemplateId        // 默认 "envelope"，记忆上次
category 默认值: "低谷与重生" → "无题"                   // 新默认盒
ACHIEVEMENT_CATEGORIES: 追加 "无题"（第 13 项）
```

- **IndexedDB**：schema 升一版，旧记录回填 `templateId = "envelope"`；`category` 旧值不动。
- **Supabase**：迁移 `ALTER TABLE passport_private.stamps ADD COLUMN template_id text NOT NULL DEFAULT 'envelope';`，RPC `life_passport_api` 加 `p_template_id text default 'envelope'` 透传。
- **向后兼容**：读取路径 `templateId ?? "envelope"`；`"无题"` 仅是新默认值与第 13 个枚举项，旧数据零操作。
- 灵感库 96 条保持原 12 类不变（灵感条目不该预置"无题"）。

## 6. 渲染引擎（`passport-renderer.ts` 升级）

```
passport-templates.ts
  ├─ PRIMITIVES: scallopStamp / postmark(椭圆+波浪销票线) / boardingTag /
  │              badgeTriangle / twine / kraftBox(盒+涂鸦+名) / cardStack
  ├─ MASCOTS: Record<Category, Path2D>   // 13 只换装鲸头鹳，页面 SVG 与 Canvas 同源路径常量
  └─ TEMPLATES: Record<TemplateId, { draw(ctx, draft, photo, mascot) }>  // 6 套
```

- 页面预览（书桌卡、盒架缩略、扇形展开）与导出海报共用 `TEMPLATES[id].draw()`，按 `scale = width/1080` 统一坐标系。
- 渲染前 `await document.fonts.load()`。
- 导出海报构图 = 记录卡 + 所属主题盒（盒涂鸦+主题名+计数），已确认。

## 10. 风险与边界

1. **版权红线**：Tinytype 素材一律不入库；`.tmp-design-ref/` 在 P1 开工前删除。
2. **`无题` 枚举扩散**：全站若有按 `ACHIEVEMENT_CATEGORIES` 遍历的 UI/统计，需确认能容纳第 13 项（实施 P2 时排查）。
3. **旧海报回归**：历史印章重新导出变新构图（预期）；已存 PNG 不受影响。
4. **模板记忆**：localStorage 键 `passport.lastTemplate`，无痕模式回退 `envelope`。
5. **扩展**：新模板 = 一个 `draw()` + 一条注册；新主题盒 = 一条 lineup 配置 + 一只涂鸦。
