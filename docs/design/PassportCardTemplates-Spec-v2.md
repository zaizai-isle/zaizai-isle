## 1. 一句话定义

**护照 = 一个带专属吉祥物涂鸦和主人名字的牛皮纸收纳盒；每枚印章记录 = 从盒中抽出的一张拟物模板卡**（信封、奖状、方子卡……），卡片由可组合的"邮驿零件"（邮票、邮戳、登机牌、麻绳、贴纸）现场拼装，页面预览与导出海报共用同一套绘制引擎。

## 2. 参考模板系统拆解（7 张预览图归纳）

### 2.1 共享骨架（所有模板一致）

| 层 | 元素 | 规格 |
|---|---|---|
| L0 | 牛皮纸收纳盒 | 前板 + 上沿高光边；左侧**动物线描涂鸦**，右侧**主人名字**（大号手写） |
| L1 | 后层卡片 ×1~2 | 同尺寸纸卡，旋转 ±2~3°、偏移 10~20px，露出边缘，暗示"一叠" |
| L2 | 前层卡片 | 拟物物件本体，微旋转 -2°~+1°，承载全部记录内容 |

### 2.2 前层卡片 = 物件隐喻（每套一个气质）

| 参考模板 | 物件 | 关键零件 |
|---|---|---|
| 路易 | 航空信封 | 齿边邮票（图案+面值）、椭圆邮戳+波浪销票线、登机牌、三角徽章、小方章、斜拉麻绳、竖排品牌字、红白航空角标 |
| 亮亮 | 复古手机 | 绿 LCD 屏像素短信、信号/电量图标、贴纸（雏菊/彩虹心）、笑脸贴 |
| 拉尔夫 | 方格演算纸 | 橙色日期格 `FRI 13\|08`、几何辅助线、大字宣言 |
| tsuki | 极简奶油卡 | 细横线、松纹章、英文日期、竖排 TINY/TYPE、小动物涂鸦 |
| 主任 | 橙色奖状 | 大红描边标题、波浪下划线、正文"鉴于…特发此状"、圆形公章、落款 |
| 老师傅 | 旧方子卡 | 切角双线框、朱红"记录"印、竖排日期、 turtle 小印 |
| 迈尔斯 | 文件夹+松紧带 | 季节大标题 `SPRING -春-`、燕子圆形邮戳、索引标签（MON/TUE/THU）、横向松紧带 |

### 2.3 归纳出的设计语法

1. **内容即贴纸**：日期、地点、正文都不是排版元素，而是"贴/盖/写"在物件上的实体（邮戳=日期、手写=正文、登机牌=地点）。
2. **零件可组合**：邮票/邮戳/徽章/麻绳/贴纸是独立零件，按模板自由组合，同一零件跨模板复用但换色换形。
3. **一卡一人格**：模板选择表达记录的气质（旅行→信封、荣誉→奖状、日常→方子卡）。
4. **盒子是身份**：吉祥物+名字让每个用户的盒子独一无二。

## 5. 数据模型变更（已获作者确认：多模板可选）

```
StampDraft / Stamp 新增: templateId: TemplateId   // 默认 "envelope"
```

- **IndexedDB**：`passport-repository.ts` schema 升一个版本号，`onupgradeneeded` 为旧记录回填 `templateId = "envelope"`，不迁移其他字段。
- **Supabase**：新增迁移 `supabase/migrations/<ts>_passport_template_id.sql`：`ALTER TABLE passport_private.stamps ADD COLUMN template_id text NOT NULL DEFAULT 'envelope';` RPC `life_passport_api` 入参加 `p_template_id text default 'envelope'` 透传。
- **向后兼容**：所有读取路径 `templateId ?? "envelope"`，旧数据零操作。
- 创建页新增"模板选择"贴纸条（6 选 1，选中贴胶带），默认按主题自动预选、可手动改。

## 6. 渲染引擎架构（`passport-renderer.ts` 升级）

```
passport-templates.ts        // 新增：模板注册表 + 共享绘制原语
  ├─ PRIMITIVES
  │   ├─ scallopStamp(ctx, x,y,w,h, {bg, drawInner})   // 齿边邮票
  │   ├─ postmark(ctx, cx,cy, rx,ry, {text, sub})       // 椭圆邮戳+波浪销票线
  │   ├─ boardingTag(ctx, …) / badgeTriangle(ctx, …)     // 登机牌/三角徽章
  │   ├─ twine(ctx, x1,y1,x2,y2)                        // 麻绳（正弦+虚线双股）
  │   ├─ kraftBox(ctx, {mascot, name})                  // 收纳盒（前板+上沿）
  │   └─ cardStack(ctx, count)                          // 后层错位卡
  └─ TEMPLATES: Record<TemplateId, Template>            // 6 套，各自 draw()
```

- **页面预览与导出共用**：护照首页缩略图、详情弹层、导出海报调用同一 `TEMPLATES[id].draw()`，只是 canvas 尺寸不同（预览 540×960 / 导出 1080×1920，内部按 `scale = width/1080` 统一坐标系）。
- 渲染前 `await document.fonts.load()` 等待手写体就绪。
- 鲸头鹳涂鸦以**内联 Path2D 路径**进入 Canvas（不引 SVG 文件），页面端用同名 SVG 组件，两者路径数据同源一份常量。

## 7. 页面结构

### 7.1 护照首页 `/achievement/passport`
- **Hero = 打开的收纳盒**：盒（鲸头鹳线描 + 主人昵称）+ 从盒中抽出的最近一张记录卡（真实模板缩略图）+ 后层 1~2 张错位卡；右侧小字 `passport /` 与护照号。
- 记录列表：每项渲染为迷你模板卡（同一注册表缩略绘制），hover 时卡片从"盒"里上浮 4px。
- 保留现有：云/本地状态、删除确认、海报弹层——只换皮，不减功能。

### 7.2 创建页 `/achievement`
- 新增"模板"贴纸选择条（6 枚迷你卡横滑，选中右上角贴 `tt-tape.svg`）。
- 预览区即真实模板实时渲染（现有 canvas 换用注册表）。
- 其余步骤结构不动。

## 8. 原创 SVG / 路径资产清单

| 资产 | 形式 | 用途 |
|---|---|---|
| `shoebill-line.svg` + 同源 Path2D 常量 | 线描鲸头鹳（戴小帽） | 盒子涂鸦、空状态 |
| `tt-tape.svg` | 半透明和纸胶带 | 模板选中态 |
| 邮票内芯图案 ×6（邮筒/相机/奖杯/锅/燕子/三角尺） | Canvas 原语内联路径 | 齿边邮票内图案，按主题取用 |
| 波浪销票线、麻绳、松紧带 | Canvas 正弦路径 | 生成式，无文件 |

全部原创，合计新增文件 < 20KB；点阵、格线、虚线均为 CSS/Canvas 生成，零图片请求。

## 9. 性能契约合规

- [x] 模板注册表为纯函数模块，随路由级 CSS 同侧加载，无新依赖、无新 Provider
- [x] 缩略图与海报共用一次渲染逻辑，不重复绘制；列表缩略图用 540 宽低分辨率 canvas

## 11. 风险与边界

1. **版权红线**：参考包素材一律不入库；`.tmp-design-ref/` 在 P1 开工前删除。
2. **旧海报回归**：历史印章重新导出将变为新"盒+卡"构图（预期行为）；已保存的旧 PNG 不受影响。
3. **无照片记录**：`polaroid` 模板无照片时自动降级为 `recipe` 底 + 大字正文。
4. **昵称缺省**：护照未命名时盒子显示 `再再` 占位。
5. **模板扩展**：注册表开放，后续新增模板 = 新增一个 `draw()` + 一条注册，不动页面。
