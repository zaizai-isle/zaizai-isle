## 1. 策划结论

- 首批20期包含16篇单件观察和4篇关联阅读。
- 四组内容分别检验图像观看、日常物品、视觉传播、空间与数字交互。
- 所有单件观察均指定一个主要 A 主题、一种主要 M 方法和一个主要 B 节点。
- 表中期数为**策划序号**。它不是发布日期。不得修改已发布条目、历史反馈和内容版本。
- 关联阅读允许独立阅读。它不能要求用户先完成其他内容。
- 所有内容必须通过史实、图片许可、图片可达性和发布前审核。

## 3. 单篇核心发现与关联方向

| 序号 | 可观察的内容或比较依据 | 本期希望迁移的观察方式 |
| --- | --- | --- |
| 01 | 浪、山和船上人物的相对尺度 | 比较主体和参照物的大小 |
| 02 | 色彩浓淡和印制媒介的关系 | 观察颜色和媒介，而非仅观察题材 |
| 03 | 对应构图中的视角、轮廓和颜色差异 | 比较临摹与改写的可见选择 |
| 04 | 人物朝向和取景引导视线 | 区分可见事实、观者推测和被摄者经历 |
| 05 | 比较画面组织、制作媒介和传播语境 | 跨作品分析不等于历史影响 |
| 06 | 纹样重复、方向和变化 | 分析连续图案的视觉节奏 |
| 07 | 钢管框架与承托面改变视觉体量 | 观察材料与结构的关系 |
| 08 | 图案的几何关系与纺织设计意图 | 区分设计稿与完成织物 |
| 09 | 部件布局、材质与操作关系 | 观察功能布局与视觉一致性 |
| 10 | 比较装饰、材料、制造与功能目标 | 不要把历史写成从装饰到简洁的进步线 |
| 11 | 透视、斜线和文字与轨道的关系 | 分析静态画面的运动感 |
| 12 | 图文共同表达对报刊的讽刺 | 结合当时的媒体和文化语境理解符号 |
| 13 | 图例、数量编码、重复和色彩 | 先读图例，再解释图符的计量含义 |

| 19 | 触摸屏中的控件、软键盘与反馈 | 比较操作方式与交互提示 |
| 20 | 比较空间、器物和数字界面的使用关系 | 比较问题相似，不推断同一继承链 |

## 4. 四篇关联阅读的编辑边界

| 策划序号 | 必须回答的问题 | 必须避免的解释 |
| --- | --- | --- |
| 05 | 图像如何通过构图、媒介、取景和传播影响观看？ | 不将不同地域作品写成单向影响路径。 |
| 10 | 不同设计师如何处理装饰、材料、结构、制造和使用？ | 不得得出“简洁必然优于装饰”的结论。 |
| 15 | 广告、讽刺画、统计图和线路图各要让读者完成什么任务？ | 不将信息简化视为所有视觉传播的唯一标准。 |
| 20 | 建筑、家具和数字产品怎样组织观看及使用行为？ | 不将不同媒介写成单一技术继承链。 |

## 5. 内容关系管理

- **观察方法关联**：只说明值得比较的视觉方法。不声称历史影响。
- **历史发展关联**：需要记录具体传播事实、社会条件或观念差异。
- 当前优先比较：01↔03、06↔08、06↔07、07↔09、09↔17、11↔14、13↔18、14↔19。
- 连接类型固定使用 C01 历史影响、C02 方法比较、C03 观察迁移。

## 6. 覆盖检查

- 16篇单件观察已覆盖 A01–A08 八个观察主题。
- 六种观察方法 M01–M06 均有适用内容。M06 主要见关联阅读。
- 历史框架偏重现代设计。H03、H04、H08 缺少独立代表作品。后续补足。
- 建筑和非欧美地区作品数量仍有限。第二批重点补足。
- 覆盖情况不构成固定配额。编辑以作品质量为优先条件。

## 7. 内容就绪条件

每期必须同时通过以下检查：

1. 锁定具体作品与馆藏版本。
2. 核实作者、年代、媒介、主要历史事实。
3. 为主图与全部必要的对照图记录权利依据。
4. 确认正式环境可稳定访问图像。
5. 完成单篇或关联阅读的正文及事实审核。
6. 将正式发布内容保存为独立版本。不要覆盖历史快照。
