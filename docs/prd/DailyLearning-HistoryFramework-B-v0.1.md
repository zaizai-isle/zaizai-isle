## 1. 目标与范围

**历史认知框架 B 用于解释当代视觉文化与设计方式的历史形成过程。**

框架支持三个工作目标：

1. 为长期选题建立历史范围和研究问题。
2. 为具体作品提供历史背景和可核实的关联。
3. 检查内容策划在时代、地区、媒介和设计观念上的缺口。

### 1.1 研究范围

- **研究重点**：约19世纪中后期至今的现代视觉文化与现代设计。
- **必要回溯**：更早时期的图像、文字、工艺、建筑和审美传统。
- **地区范围**：不同地区各自的发展及跨文化联系。不得以欧洲艺术史分期替代其他地区的历史分期。
- **研究对象**：绘画、版画、摄影、字体、书籍、海报、工艺、产品、建筑、信息设计和数字交互。
- **内容限制**：本框架不是完整世界艺术史目录。首轮节点用于指导选题，不代表最终分类。

### 1.2 历史解释要求

- 研究历史变化的社会、文化、技术和生产条件。
- 区分直接影响、回应、并行实践和条件变化。
- 不把形式相似直接视为历史影响。
- 不将艺术与设计史写成单一的进步过程。
- 保留不同地区、群体和设计实践之间的差异。
- 将历史事实、研究假设和编辑比较分别记录。

### 3.1 线索使用规则

- B1–B5 主要按研究对象组织内容。
- B6、B7 作为贯穿性研究视角。它们也允许形成独立内容。
- 一件作品通常对应一条主要线索，并可关联其他线索。
- 不为满足分类覆盖而将不相关作品强行关联。

### 3.2 各线索的主要研究范围

**B1｜图像与观看方式**

- 不同文化的图像表现、空间表达和视觉叙事。
- 透视、写实、象征和抽象的不同用途。
- 摄影、电影和数字图像的制作与观看。

**B2｜文字、印刷与视觉传播**

- 书写传统、书籍、木版印刷与机械化印刷。
- 商业海报、字体排印、图文关系与视觉识别。
- 数字字体、屏幕排版与网络传播。

**B3｜工艺、工业与产品设计**

- 器物、材料、制造与使用方式。
- 工业化带来的生产变化与设计争论。
- 现代家具、战后工业产品与当代制造。

**B4｜建筑、空间与现代生活**

- 建筑材料、结构、空间观念与公共用途。
- 工业城市、现代住宅和城市规划。
- 地域实践、公共空间和可持续设计。

**B5｜信息组织与交互设计**

- 地图、统计图表、公共导向和信息系统。
- 图形界面、人机交互和移动设备。
- 数字产品的信息层级、操作与反馈。

**B6｜艺术观念与审美变革**

- 艺术的社会用途、艺术制度和审美观念。
- 现代艺术中的形式实验和艺术边界讨论。
- 观念艺术、当代艺术和新的媒介实践。

**B7｜文化交流、社会与审美身份**

- 各地区自身的视觉传统和现代发展。
- 贸易、迁徙、殖民与文化交流。
- 性别、阶层、身份、消费和全球传播。

### 6.2 节点研究要点

**H01｜不同文明的图像与空间表达**

- 比较不同文化中的空间、比例、象征和叙事方法。
- 不将欧洲线性透视作为所有图像传统的统一标准。
- 作品入口：中国山水、欧洲透视绘画、日本版画等具体作品。

**H02｜文字、书籍与图像复制**

- 研究东亚木版印刷、书写与欧洲印刷等不同技术传统。
- 区分图像复制技术与具体视觉表达。
- 作品入口：《十竹斋书画谱》具体图页。

**H03｜工艺、材料与物品制造**

- 研究材料、工艺、礼仪、身份、功能与器物形态的关系。
- 作品入口：有可靠资料的家具、陶瓷、纺织及金属器物。

**H04｜工业化与现代生活**

- 研究机械生产、城市交通、市场与消费方式的变化。
- 分析不同设计改革对工业化的不同回应。

**H05｜摄影、城市与现代观看**

- 研究摄影制作、取景、传播与纪实用途。
- 区分照片记录的画面和公众对被摄者的解释。
- 作品入口：《移民母亲》。

**H06｜跨文化图像传播**

- 研究作品、媒介和观念跨地区传播的具体渠道。
- 使用有来源的个案，不把形式相似视为直接影响。
- 作品入口：歌川广重版画与梵高的临摹作品。

**H07｜工艺美术与设计改革**

- 研究19世纪工业化环境下的工艺、劳动与生产争论。
- 不把工艺美术运动概括为单一装饰风格。
- 作品入口：William Morris 的具体织物或壁纸设计。

**H08｜现代艺术的形式实验**

- 研究色彩、抽象、视角和艺术媒介的实验。
- 比较不同运动的目标、差异和历史背景。
- 当前作品入口不足。后续补充。

**H09｜现代主义与设计教育**

- 研究包豪斯及其他现代设计教育实践。
- 关注材料、工艺、形式、生产和社会目标。
- 作品入口：瓦西里椅、Anni Albers 的纺织设计稿。

**H10｜现代平面设计与视觉传播**

- 研究海报、字体、图文排版和大众传播。
- 比较商业、政治和公共传播的不同需求。
- 作品入口：《Nord Express》、墨西哥大众印刷品。

**H11｜信息设计与视觉系统**

- 研究图符、数据编码、交通网络和导向系统。
- 明确信息取舍对使用任务的影响。
- 作品入口：Isotype 图表、1933年伦敦地铁线路图。

**H12｜战后工业设计与大众消费**

- 研究产品布局、生产、功能和消费文化。
- 不将战后设计发展归因于单一设计师或品牌。
- 作品入口：Braun SK 4/10。

**H13｜现代建筑与生活空间**

- 研究建筑材料、空间、居住方式及地域实践。
- 同时关注现代主义城市规划受到的批评。
- 作品入口：巴拉甘自宅与工作室。

**H14｜后现代设计与审美多元化**

- 研究对现代主义部分主张的回应及设计多样性。
- 不将后现代设计简化为增加装饰。
- 作品入口：Ettore Sottsass《Carlton》。

**H15｜图形界面与数字视觉**

- 研究窗口、图标、菜单、指针等图形交互机制。
- 不将图形界面的发展归因于单一公司。
- 作品入口：Xerox Alto、1984年 Macintosh。

**H16｜网络、移动与智能设计**

- 研究网络传播、触控交互、平台和智能系统。
- 区分已经发生的设计变化与未来预测。
- 作品入口：2007年初代 iPhone、其他经核实的交互设计案例。

## 7. 历史节点关联规则

### 7.1 关系类型

| 类型 | 固定术语 | 判定标准 |
| --- | --- | --- |
| K1 | 影响与传播 | 有文献、作品记录或传播证据支持具体影响。 |
| K2 | 回应与反思 | 后续实践明确回应某种既有条件或观念。 |
| K3 | 并行与比较 | 可比较实践存在共同问题；不声称直接影响。 |
| K4 | 条件与变化 | 技术、经济或社会条件影响实践可能性。 |

每条关系必须记录依据。关系存在不代表可以省略具体说明。

### 7.2 首批候选关系

| ID | 关联节点 | 研究问题 | 类型 | 当前状态 |
| --- | --- | --- | --- | --- |

| R02 | H04 → H07 | 工业化为什么引发设计改革？ | K2 | 需落实具体史料 |
| R03 | H06 → H08 | 日本版画如何影响部分欧洲艺术实践？ | K1 | 有代表性个案；需逐案核实 |
| R04 | H07 ↔ H09 | 工艺美术与现代主义如何回应不同生产问题？ | K2、K3 | 比较议题 |
| R05 | H08 ↔ H09 | 现代艺术实验与设计教育有哪些具体联系？ | K1、K3 | 需落实机构与人物 |
| R06 | H09 ↔ H12 | 现代主义实验与战后产品设计有哪些联系与差异？ | K3 | 不预设直接传承 |
| R07 | H10 ↔ H11 | 视觉传播和信息设计如何回应不同任务？ | K3 | 比较议题 |
| R08 | H11 ↔ H15 ↔ H16 | 信息组织与数字交互有哪些方法联系和差异？ | K3、K4 | 需区分方法与影响 |

### 7.3 关系的证据边界

- 有历史影响证据时，记录传播对象、时间、渠道和出处。
- 仅有形式相似时，使用“并行与比较”。
- 同时出现的历史变化不自动构成因果关系。
- 跨文化研究需保留原地区作品的独立历史价值。
- 研究方向不得在已发布内容中直接表述为确定结论。

### 8.1 作品入口规则

- 一件作品可以对应多个节点，但单篇应有一个主要节点。
- 单篇应有一个可观察的核心问题。
- 作品资料已核实不等于图片可发布。
- 图片使用条件不明确时，不进入每日主推。
- 历史节点可以暂时没有单篇入口。不强行选择不适合观看的作品。

## 9. 完整性与优先级检查

### 9.1 当前已覆盖

- 图像、印刷、产品、建筑、信息与数字交互等主要研究领域。
- 现代视觉文化的主要研究时期。
- 工业化、现代主义、战后设计与数字交互等重点问题。
- 影响、回应、并行与条件变化等关系类型。

### 9.2 当前不足

| 缺口 | 处理方向 |
| --- | --- |
| 非欧美地区的具体节点不足 | 补充地区自身的艺术与设计史；避免只讨论其对欧洲的影响。 |
| 建筑与空间作品不足 | 增加不同地区的建筑和公共空间案例。 |
| 艺术观念史不足 | 补充抽象艺术、观念艺术及制度背景。 |
| 工艺与服饰媒介覆盖不足 | 补充纺织、服装、材料和日常器物。 |
| 性别、阶层与劳动研究不足 | 检查代表人物和创作条件的叙述偏差。 |
| 智能设计变化快 | 区分稳定历史事实与需要持续核验的现状。 |

建议持续关注中国及东亚、南亚、西亚、非洲、拉丁美洲等地区的研究。不得以地区配额替代作品和史料质量判断。

### 9.3 节点优先级

| 等级 | 定义 | 策划方式 |
| --- | --- | --- |
| 核心节点 | 直接解释当前重点历史问题 | 安排多件作品和关联阅读 |
| 支撑节点 | 提供理解核心节点所需的背景 | 按需选择代表作品 |
| 拓展节点 | 有独立研究价值，暂不优先展开 | 保留研究入口 |

优先级不代表作品价值高低。后续可以根据研究结果调整。

## 10. 历史节点记录格式

每个节点应保留以下字段。

| 字段 | 要求 |
| --- | --- |
| `node_id` | 稳定编号，例如 H09 |
| `name` | 使用本文件固定术语 |
| `core_question` | 一个明确的研究问题 |
| `periods` | 关联 T1–T8；补充实际年代 |
| `regions` | 明确涉及的地区与文化 |
| `context` | 社会、技术、文化背景 |

| `debates` | 重要观念与分歧 |

| `relations` | 关联节点、关系类型与证据 |
| `works` | 代表作品及具体馆藏 |
| `current_connections` | 具体当代连接及其关系类型 |
| `sources` | 博物馆、学术著作或其他可信资料 |
| `open_questions` | 争议、证据缺口和待核实内容 |
| `research_status` | 节点研究状态 |

### 10.1 研究状态

| 状态 | 定义 |
| --- | --- |
| 框架已提出 | 已明确研究问题，尚未完成关键事实核实。 |
| 史实已核实 | 核心事实与重要历史论断具有可追溯来源。 |
| 可用于内容策划 | 已找到适合观看的具体作品和观察切入点。 |
| 可发布 | 内容审核、图片许可及正式展示条件均已通过。 |

状态按实际结果记录。不得将“可用于内容策划”直接标记为“可发布”。

## 11. 参考资料与使用规则

建议优先使用以下资料类型：

| 来源 | 用途 |
| --- | --- |

资料使用要求：

1. 每个历史论断记录对应来源。
2. 作品资料与图片许可分别核查。
3. 不将单一博物馆分类视为完整世界艺术史。
4. 研究资料和编辑推断应分别记录。
5. 不以 AI 生成内容替代事实核验。
