## 1. 目标与使用边界

**观察体系 A 用于指导作品观察内容。** 体系不构成用户必须完成的课程。

观察体系 A 解决三个问题：

1. **观察什么**：确定作品中的主要视觉对象或关系。
2. **怎样观察**：确定引导用户观察、比较和求证的方法。
3. **长期发展什么能力**：检查持续阅读是否支持具体观察与判断。

观察体系 A 与[历史认知框架 B](./DailyLearning-HistoryFramework-B-v0.1.md)共同指导选题。单篇内容不需要展示内部编码。

### 1.1 观察层次

| 层次 | 定义 | 示例 |
| --- | --- | --- |
| 可见事实 | 画面、物品或空间中可以直接核对的信息 | 两个孩子背对镜头。 |
| 编辑解释 | 根据可见依据提出的合理解释 | 人物朝向使观看重点集中于母亲。 |
| 个人感受 | 用户的主观体验 | 这张照片让我感到不安。 |

编辑必须区分三类内容。个人感受没有统一答案。编辑解释不得冒充创作者意图或历史事实。

## 2. 体系结构

| 组成 | 编码 | 数量 | 用途 |
| --- | --- | ---: | --- |
| 观察主题 | A01–A08 | 8 | 确定主要观察对象 |
| 观察方法 | M01–M06 | 6 | 确定内容的引导方式 |
| 能力发展方向 | D01–D04 | 4 | 检查长期内容的能力覆盖 |

这些组成相互交叉，不形成顺序关系。同一作品可以对应多个观察主题。单篇原则上只选择一个主要观察主题和一种主要观察方法。

## 3. 八个观察主题

| ID | 固定术语 | 核心问题 | 主要观察对象 | 适用媒介 |
| --- | --- | --- | --- | --- |
| A01 | 构图与空间 | 元素如何组织位置与空间？ | 视角、前后关系、留白、视觉重心、空间深度 | 绘画、摄影、建筑、界面 |
| A02 | 比例与尺度 | 大小关系如何影响观看？ | 相对尺度、比例、人体尺度、视觉重量 | 绘画、家具、海报、建筑 |
| A03 | 色彩与光影 | 色彩和明暗如何影响观看？ | 色相、明度、冷暖、对比、光源、阴影 | 绘画、印刷、摄影、空间 |
| A04 | 线条、形态与节奏 | 形态如何产生方向和节奏？ | 直线、曲线、几何形、重复、疏密、动势 | 海报、织物、家具、建筑 |
| A05 | 材料、结构与功能 | 制作和使用条件如何影响形态？ | 材料、连接、承重、工艺、操作、使用 | 工艺品、家具、建筑、产品 |
| A06 | 文字、符号与图文关系 | 文字和图像如何共同传递意义？ | 字体、字级、图标、象征、图文组合 | 书籍、海报、品牌、界面 |
| A07 | 信息组织与视觉秩序 | 如何组织信息以支持理解与操作？ | 层级、网格、分类、简化、导航、反馈 | 地图、图表、产品、界面 |
| A08 | 叙事、象征与情绪 | 作品如何表达意义并引发感受？ | 人物、情境、象征、叙事、文化语境 | 绘画、摄影、广告、当代艺术 |

### 3.1 A01｜构图与空间

- **观察重点**：主体与背景、位置、观看顺序、透视和空间关系。
- **建议提问**：为什么先注意这一处？为什么画面保留较大留白？
- **可迁移对象**：摄影取景、海报布局、建筑空间和页面布局。
- **主要关联 B**：B1 图像与观看方式、B2 文字、印刷与视觉传播、B4 建筑、空间与现代生活。

### 3.2 A02｜比例与尺度

- **观察重点**：元素相对大小、人物参照、尺度变化和视觉重量。
- **建议提问**：浪与远处的山相比有多大？人物让环境显得如何？
- **示例**：《神奈川冲浪里》。
- **主要关联 B**：B1 图像与观看方式、B3 工艺、工业与产品设计、B4 建筑、空间与现代生活。

### 3.3 A03｜色彩与光影

- **观察重点**：色彩分布、浓淡、明暗、材料与印刷表现。
- **建议提问**：哪些颜色相互形成对比？色彩层次与制作方式有什么关系？
- **示例**：《十竹斋书画谱》中的具体图页。
- **主要关联 B**：B1 图像与观看方式、B2 文字、印刷与视觉传播、B6 艺术观念与审美变革。

### 3.4 A04｜线条、形态与节奏

- **观察重点**：线条方向、重复、变化、形态节奏和运动感。
- **建议提问**：静止海报为什么会产生速度感？重复单元怎样形成节奏？
- **示例**：《Nord Express》、Morris 的连续纹样。
- **主要关联 B**：B1 图像与观看方式、B2 文字、印刷与视觉传播、B6 艺术观念与审美变革。

### 3.5 A05｜材料、结构与功能

- **观察重点**：材料特性、受力与连接、制造方式、功能布局和使用需求。
- **建议提问**：哪些构件承担支撑功能？材料为什么影响视觉体量？
- **示例**：瓦西里椅。
- **约束**：不能仅凭照片断言产品舒适性、生产成本或具体设计意图。
- **主要关联 B**：B3 工艺、工业与产品设计、B4 建筑、空间与现代生活。

### 3.6 A06｜文字、符号与图文关系

- **观察重点**：字体形态、字级、图符、符号含义和文字与图像的组合。
- **建议提问**：文字和图像分别承担什么信息任务？不同字体会改变什么？
- **示例**：海报、讽刺印刷品、桌面图标。
- **主要关联 B**：B2 文字、印刷与视觉传播、B5 信息组织与交互设计。

### 3.7 A07｜信息组织与视觉秩序

- **观察重点**：信息取舍、分类、对齐、网络关系、视觉反馈和导航。
- **建议提问**：地图保留了什么信息？它省略了什么？
- **示例**：伦敦地铁线路图、Isotype 图表。
- **主要关联 B**：B2 文字、印刷与视觉传播、B5 信息组织与交互设计。

### 3.8 A08｜叙事、象征与情绪

- **观察重点**：人物关系、叙事情境、文化符号和个人解释。
- **建议提问**：照片实际展示了什么？哪些情绪判断属于推测？
- **示例**：《移民母亲》、具有社会语境的印刷品。
- **约束**：观念艺术不一定能仅通过形式分析理解。必要时应将展示语境和历史证据作为重点。
- **主要关联 B**：B1 图像与观看方式、B6 艺术观念与审美变革、B7 文化交流、社会与审美身份。

## 4. 六种观察方法

| ID | 固定术语 | 操作定义 | 单篇中的常见形式 |
| --- | --- | --- | --- |
| M01 | 感受与描述 | 先记录初步感受，再寻找可见特征。 | 完整作品与简短引导 |
| M02 | 局部拆解 | 观察关键细节，再返回整体。 | 主图与局部图 |
| M03 | 比较与对照 | 比较不同作品、版本或设计方案。 | 双图对照与差异说明 |
| M04 | 寻找依据与提出疑问 | 区分观察、推测和需要核实的信息。 | 事实与解释的对照 |
| M05 | 情境与视角转换 | 结合使用者、创作者或历史情境分析对象。 | 场景问题与背景资料 |
| M06 | 迁移与重新观看 | 将已使用的方法应用到新作品或再次观看。 | 关联阅读、回看提示 |

### 4.1 方法使用要求

- M01 不要求用户提交感受文字。
- M02 的局部图片必须支持具体观察目的。
- M03 不以判定哪件作品更先进为目标。
- M04 应当标明证据缺口。不得将推测写成事实。
- M05 的历史情境想象不得替代史料。
- M06 可以只用一句提示完成。不设课后任务。

六种方法不形成固定学习流程。单篇可组合使用。关联阅读通常优先使用 M03 和 M06。

## 5. 四个能力发展方向

| ID | 固定术语 | 发展方向 | 可观察的自然表达变化 |
| --- | --- | --- | --- |
| D01 | 观察具体化 | 从整体感受转向具体特征。 | 从“有力量”到指出构图和线条。 |
| D02 | 理解关系 | 从识别单个元素转向分析元素关系。 | 从“有一座山”到分析浪与山的尺度。 |
| D03 | 解释与判断 | 根据证据和背景形成个人判断。 | 区分照片呈现的事实与个人推测。 |
| D04 | 迁移与更新 | 跨作品使用观察方法，允许改变既有理解。 | 再次观看时提出不同解释。 |

### 5.1 使用边界

- 不设置能力分数或等级。
- 不根据反馈内容长度判断能力。
- 不把专业术语使用量作为能力指标。
- 不强制用户写观察结论。
- 四个方向用于编辑评审，不用于评价个人。

## 6. 观察体系 A 与历史框架 B 的协同

单篇内容采用以下策划单位：

**具体作品 + 核心观察问题 + 主要观察主题 A + 主要观察方法 M + 主要历史节点 B。**

| 作品 | 主要 A | 主要 M | 主要 B 节点 | 单篇核心发现 |
| --- | --- | --- | --- | --- |
| 《神奈川冲浪里》 | A02 | M02 | H01 | 相对尺度影响视觉张力。 |
| 《十竹斋书画谱》图页 | A03 | M02 | H02 | 视觉效果与图像制作方式有关。 |
| 《移民母亲》 | A08 | M04 | H05 | 照片呈现的瞬间不等于完整生活。 |
| 瓦西里椅 | A05 | M02 | H09 | 材料与结构影响视觉体量。 |
| 《Nord Express》 | A04 | M01 | H10 | 线条与透视可以形成运动感。 |
| 伦敦地铁线路图 | A07 | M03 | H11 | 信息表达需要根据使用目的取舍。 |
| Braun SK 4 | A07 | M02 | H12 | 功能布局与统一性影响视觉秩序。 |

以上条目是编辑映射，不构成已审核的发布清单。具体馆藏、图片许可和历史论断应逐项核实。

### 6.1 两类关联

| 类型 | 判定依据 | 历史证据要求 |
| --- | --- | --- |
| 观察方法关联 | 不同作品适合使用相同的观察方法。 | 不要求直接历史联系；不得声称存在直接影响。 |
| 历史发展关联 | 作品的传播、观念、技术或背景存在研究关系。 | 声称直接影响时，必须提供史料。 |

示例：

- 《神奈川冲浪里》与现代海报可以比较尺度方法。比较不自动证明历史影响。
- 瓦西里椅与 Braun SK 4 可以研究材料、功能与视觉秩序的不同历史实践。具体影响关系需核实。

## 7. 单篇内容策划字段

| 字段 | 必填 | 用途 |
| --- | --- | --- |
| 作品 ID 与资料 | 是 | 唯一识别观察对象 |
| 选题理由 | 是 | 说明作品的观察价值 |
| 核心观察问题 | 是 | 形成单篇引入 |
| 主要观察主题 A | 是 | 限定主要观察对象 |
| 主要观察方法 M | 是 | 确定叙事方式 |
| 次要观察主题 | 否 | 记录必要的交叉内容 |
| 可见依据 | 是 | 支持编辑解释 |
| 本期核心发现 | 是 | 限定单篇的信息范围 |
| 主要历史节点 B | 是 | 连接历史研究 |
| 必要历史背景 | 是 | 解释本期发现 |
| 当代连接或迁移 | 是 | 提供后续观察入口 |
| 关联作品 | 否 | 支持跨作品内容 |
| 史料与图片状态 | 是 | 控制发布条件 |

详细写作与审核要求参见[单篇内容编辑规范 v0.1](./DailyLearning-EditorialGuidelines-v0.1.md)。

## 8. 前 20 期的覆盖检查

首轮策划按以下条件检查。条件用于评审，不作为硬性配额。

1. 八个观察主题中，至少六个得到具体作品验证。
2. 六种观察方法中，至少四种得到实际使用。
3. 涵盖多种媒介。避免长期集中于平面设计和数字产品。
4. 至少安排少量作品对照与历史关联阅读。
5. 允许自由探索选题。不得为了分类数量强行选择作品。
6. 单篇必须可独立阅读。不得依赖完成前置课程。

### 8.1 待验证问题

- A01–A08 能否覆盖建筑、电影、互动装置和观念艺术。
- M04、M05、M06 如何在轻量阅读中自然呈现。
- 图片形式如何适配不同媒介，且不形成固定模板。
- 观察主题数量与内容媒介分布是否需要调整。

框架调整应以真实作品和样稿评审为依据。
