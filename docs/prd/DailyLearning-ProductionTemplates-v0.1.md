# 每日一看｜内容生产工作模板 v0.1

> 用途：将策划项目转换为待审核内容。填写完成不代表允许发布。  
> 依据：[单篇内容编辑规范](./DailyLearning-EditorialGuidelines-v0.1.md)

## 1. 统一状态与责任

内容状态固定使用：

1. `candidate`：选题候选。
2. `researching`：史料及作品版本核实中。
3. `draft`：正文和图文方案已成稿。
4. `reviewed`：事实、解释和文字审核完成。
5. `asset_cleared`：全部必要图片已完成许可与文件核查。
6. `ready`：事实审核、图片授权、图片可达性和版本锁定均通过。
7. `published`：已正式发布；禁止无版本记录的覆盖。

`reviewed` 和 `asset_cleared` 是不同的审核结果。不能以其中一项代替另一项。

> “先看、发现、理解、连接、回应”是编辑标签。正式页面不强制保留五个章节标题。

检查规则：

- 一条关键论断对应一条具体来源或明确观察依据。
- 创作意图、直接影响和首创性主张必须单独核实。
- 事实不足时，应删除或收窄论断。
- 不用“可能”掩盖完全无证据的推断。

## 6. 提交前验收

- [ ] 作品或对照作品均已锁定具体版本。
- [ ] 主要 A、M、B 信息与本期正文一致。
- [ ] 核心发现可以通过图片或对照复核。
- [ ] 所有关键历史论断均有来源。
- [ ] 标题所问的问题已在文章中回应。
- [ ] 正文只保留必要的历史背景。
- [ ] 图片许可与文件可达性均通过。
- [ ] 页面支持查看原图并显示必要署名。
- [ ] 三种反馈与自由文字入口均保留。
- [ ] 新版本不会覆盖既有内容快照或回应。
