## 三、使用顺序

1. 根据产品定义选择内容目标。
2. 根据 A、B 体系筛选可观察作品。
3. 从20期规划中选择具有明确作品版本的候选。
4. 在史料与图片登记中核对权利及版本。
5. 使用内容生产模板完成正文。
6. 按单篇内容编辑规范审稿。
7. Agent 自动检查通过后，将固定版本送交岛主审核。
8. **岛主明确批准指定版本后**，才允许按既有流程正式发布。

**注意**：本轮交付不包含本地代码、数据库迁移或网站验收。
