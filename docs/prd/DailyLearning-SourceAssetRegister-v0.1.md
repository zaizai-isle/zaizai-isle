## 1. 状态定义

- **资料已核对**：已获得馆藏、博物馆或原始发布者提供的基本作品资料。
- **版本待锁定**：同一作品存在不同馆藏版本、图页或截图。尚未确定最终展示对象。
- **开放图像候选**：馆藏明确标注 Public Domain 或 No known restrictions。仍需确定具体图像文件。
- **许可待核实**：馆藏可阅读，但图片复用权利尚无明确依据。
- **存在版权提示**：权利人或机构明确标示版权。不可直接复制上线。
- **部署待验收**：图片许可和实际可达性是两个独立条件。

## 3. 需要优先处理的具体问题

1. **02 图页与正文一致性**：CP62 馆藏页标注 Public Domain，编号为 CP62。现有样稿描述“树枝、绿叶、红色果实”。编辑必须对照具体图页核验这些特征。不能仅凭画谱总名称推断图中内容。
2. **06 作品时间口径**：Morris 的《Strawberry Thief》设计登记于1883年。The Met 藏品 23.163.11 的印制时间为1917–1923年。页面应分别写出设计年代与实物印制年代。
3. **08 作品媒介口径**：当前选定 MoMA `3746` 是1926年的 **Preliminary Design for Wall Hanging**，媒介为水粉和铅笔纸上设计稿。不得描述为完成的织物。
4. **09 署名口径**：Braun SK 4/10 的设计者包含 Dieter Rams 和 Hans Gugelot。不能只署名 Rams。
5. **12 署名口径**：The Met 馆藏页同时列出 José Guadalupe Posada、Manuel Manilla 与出版者 Antonio Vanegas Arroyo。正文应保留作品级归属说明。
6. **14 使用许可**：1933年地铁图具有官方研究资料。London Museum 页面标有地图图像版权。不能把网页可访问视为图像复用许可。
7. **16 文本与照片权利不同**：UNESCO 页面上的历史描述和建筑照片可能采用不同许可。需按具体摄影者处理。
8. **18/19 操作界面截图**：硬件馆藏照片不能替代与阅读问题对应的历史 GUI 或初代 iPhone 真实界面。截图需另外核对年代、来源和权利。

## 4. 权利审核记录字段

每个计划展示的图像都应记录：

| 字段 | 要求 |
| --- | --- |
| asset_id | 唯一标识；不要只使用作品名称 |
| issue_id | 对应策划序号；一个作品可关联多张图 |
| institution / object_id | 机构和具体馆藏编号 |
| source_page | 可追溯的原始资料页面 |
| image_file_url | 实际下载或请求的图像文件 URL |
| rights_statement | 页面权利声明的原文或准确转述 |
| license_url | 具体许可条款或授权证明 |
| attribution | 作者、摄影者及机构的必要署名 |
| checked_on | 核查日期 |
| local_path | 本地化资源路径（如适用） |
| dimensions | 原图宽高及最终资源尺寸 |
| crop | 局部图片的源图和裁切坐标 |
| alt | 与图像可见内容一致的替代文本 |
| production_test | 正式部署环境加载结果 |

## 5. 许可和发布规则

- The Met **Public Domain** 图像可按其 Open Access/CC0 规则处理。仍要确保**该具体对象**确实标有 Public Domain。
- LOC 的 **No known restrictions** 不是所有馆藏的统一版权声明。按对应记录核查。
- MoMA、London Museum、V&A、Apple、Smithsonian 等机构的网页并不自动授予高分辨率图片复用权。
- 有版权提示的内容，默认**不发布**。编辑可以申请授权，或提出经核实的替代选题。不得自动付费、购买授权或替换已发布历史记录。
- 未通过图片许可核实的关联阅读同样不得发布。
