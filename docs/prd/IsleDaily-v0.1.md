# 小岛日签功能规格（Daily v0.1）

> 状态：Active
>
> 最后更新：2026-08-07
>
> 适用模块：`/daily`
>
> 版本体系：Daily 使用独立内部版本，不占用 Zaizai Isle 站点版本号。

## 1. 产品定位

小岛日签是岛上的时间切片：每天打开一页，在一句文字、日期与季节变化里感知此刻。它不是资讯流、打卡工具或内容运营栏目。

核心原则：

1. **一天一页**：当天内容是默认入口，历史日期可以被安静地翻阅。
2. **无使用压力**：不显示连续天数、未读数量、任务或完成率。
3. **季节可感知**：颜色、景观、节气与日期共同构成环境，不抢夺文字。
4. **内容有边界**：中文使用公版古典诗句，英文使用独立策划的小岛短句，不伪装成逐字翻译。
5. **本地计算优先**：日期、内容轮换和季节主题在静态站点中完成，不依赖后台服务。

## 2. Daily v0.1 范围

- 首页 Daily Note 卡片展示当天内容、作者、来源和日期。
- `/daily` 提供日签海报与月历视图。
- 可选择其他日期并回到今天。
- 支持中文和英文日签内容。
- 支持春、夏、秋、冬四套主题与景观预览。
- 展示农历日期和当前节气信息。
- 响应式布局适配手机与桌面端。

## 3. 数据与内容规则

- 日签由稳定日期映射到本地内容表，同一天的结果必须稳定。
- 中文与英文内容独立策划，但共享日期索引与主题。
- 内容条目至少包含正文、作者、来源和标签。
- 新增引用前必须核对作者、篇名和公版状态。
- 原创英文内容统一标记为 `Zaizai Isle / Island Note`。
- 不收集用户阅读历史，不建立个人画像。

## 4. 非目标

- 不做推送提醒、签到、连续阅读奖励或排行榜。
- 不做用户投稿、评论和社交分享流。
- 不做 AI 实时生成日签。
- 不承诺每天发布一条新的远程内容。
- 不做复杂农历排盘或民俗宜忌。

## 5. 验收标准

- 首页日签与 `/daily` 当天内容一致。
- 选择任意有效日期均能稳定显示内容。
- 中英文切换不会改变所选日期。
- 四季主题在预览和真实日期下均可恢复。
- 手机端可以完成选日期、阅读与回到今天。
- 键盘焦点、按钮标签和减少动态效果模式可用。

## 6. 后续候选

只有在 Daily v0.1 被验证为值得保留后，才评估：

- 导出单页日签图片。
- 收藏少量日期到本地。
- 为内容表增加自动校验脚本。

不优先进入：账号同步、公开收藏夹、连续签到和算法推荐。
