## 1. 当前基线与差异

### 2026-09-28 用户确认的范围变更

- 优先实施免注册云端护照：Supabase 匿名身份、私有数据库及照片存储、可下载恢复密钥、本地记录主动迁移。
- 所有人可用，各护照默认私密；恢复密钥授权新设备访问同一本护照，不要求邮箱或密码。
- 沿用 Next.js、React、TypeScript、项目 Conda / Node 25 和静态部署；用户数据仅在浏览器运行时请求，不写入静态页面。
- 云端保存明确显示成功或失败，断网不冒充保存成功；本轮不实现离线自动同步队列。
- 本地迁移保留原数据，重复迁移不覆盖已存在的云端记录。跨设备并发编辑检测冲突，不静默覆盖。
- 服务端限制每本护照记录数、照片大小、上传预留量和写入频率；匿名身份创建需结合平台 IP 频率限制，规模化开放前启用验证码与用量监控。
- 恢复密钥是访问凭证，仅保存摘要到数据库；下载文件包含原始密钥，须妥善保管。重新生成会使旧密钥失效，但不撤销已授权设备。
- 验收重点变更为：匿名保存与重新打开、另一设备持密钥恢复、跨用户隔离、照片私密、本地迁移可重试、故障不丢旧数据。
- 远端建表、匿名登录开关和真实双设备验收依赖 Supabase 管理访问；未完成前不得标记已上线。

### 2026-10-14 岛主账户补充方向

- 访客继续使用现有匿名身份、私密云端护照与恢复密钥，不增加注册要求。
- 增加一个预设的永久岛主账户，与每日学习等私人模块共用身份。
- 岛主已有匿名护照通过恢复密钥把永久账户加入成员授权，不复制记录，不自动合并护照。
- 岛主登录会话与访客匿名护照会话使用独立存储标识，登录或退出不能覆盖匿名身份。
- 本项尚未开发，不改变上文已经完成的匿名云端能力。详细方案见 [岛主账户与私人数据方案](./IslandOwnerAccount.md)。

- 当前项目：Next.js 16.1.4、React 19、TypeScript、Tailwind CSS 4。
- 运行环境：项目 `./.conda-env`；本次实测 Node.js v25.8.2。

## 3. 推荐开发顺序

| 批次 | 功能 | 用户收益 | 范围 |
|---|---|---|---|
| A：优先 | 搜索和组合筛选 | 快速找回某次抵达 | 标题/记录文字搜索；年份、分类、有无照片筛选；结果数与清空条件 |
| A：优先 | 时间线与现有海报墙切换 | 按时间回看或按画面浏览 | 时间线按年/月分组；两种视图共享筛选结果和排序 |
| A：配套 | 渐进加载与失败隔离 | 多条记录时尽早看到内容 | 列表不等待全部高清海报；按需生成海报，限制并发；单条渲染失败可重试 |
| B：后续 | 护照首页完善、年度合集 | 形成个人时间感 | 最近抵达、年度快捷入口；合集复用年份筛选，可隐藏 |
| B：后续 | 历史同日回顾 | 再次发现过去的记录 | 仅出现于往年同月同日有记录时；空缺时不制造提醒压力 |
| C：另行评估 | 护照翻页 | 增强叙事浏览体验 | 数据定位能力稳定后再设计，尊重减少动态效果设置 |
| 后续版本 | 旅程、完整备份恢复 | 长期整理与迁移 | 保留在 v0.4；如计划扩大真实使用，重新评估备份优先级 |

本轮建议仅批准 A 批次。v0.3 路线仍保留 B/C，A 完成不代表完整 v0.3 已交付。

## 4. A 批次输入、输出与边界

- 输入：当前默认护照中已有的印章记录，以及搜索词、年份、分类、照片条件和视图选择。
- 输出：匹配结果、匹配数量、按日期排列的海报墙或时间线，并保留查看、编辑、删除和 PNG 导出入口。
- 搜索：去除首尾空格，标题与记录文字按子串匹配，英文忽略大小写；空搜索词不限制结果。
- 组合规则：搜索与各筛选项取交集；年份取记录的发生日期，分类选项兼容已保存的历史分类。
- 计数：护照总数始终表示全部记录，筛选结果数单独显示。
- 日期：以已保存的日期字符串分组，避免时区转换改变日期；异常日期显示“日期待确认”，不静默丢弃记录。
- 同日排序：沿用创建时间倒序，完全相同时以稳定 ID 作为最终排序依据。
- 状态：区分加载、读取失败、护照为空和筛选无结果；无结果提供清空条件入口。
- 视图切换保留筛选条件；本批次刷新后恢复默认，不增加筛选偏好的持久化。
- 删除后更新结果数和分组，最后一条删除后显示相应空状态。
- 无照片、长标题、长中文记录和历史分类均可正常浏览。
- 图片仍只在浏览器内处理；单条海报失败不阻断其他记录和文字浏览。

## 5. A 批次验收标准

1. 在包含跨年、同日、不同分类、有图/无图的 50 条样本中，搜索和组合筛选返回准确结果。
2. 时间线与海报墙显示相同记录、顺序和结果数；清空条件恢复全部记录。
3. 0 条、1 条、50 条记录及筛选无结果时均有完整界面。
4. 列表可在全部高清海报生成前显示；一次单条渲染失败不使整个页面进入失败状态。
5. 切换视图、筛选和删除后不展示过期海报，释放不再使用的图片 URL。
6. 手机和桌面可搜索、筛选、切换视图及完成原有查看/编辑/删除/导出；键盘可操作，弹窗焦点可进入并返回触发点。
7. 旧记录刷新后仍可恢复，原有内容和照片不因新增浏览功能改变。
8. `npm run test:passport-storage`、`npm run lint`、`npm run build -- --webpack` 通过；构建所需环境变量缺失时明确记录未验证项。
9. 搜索、筛选、日期分组和同日排序覆盖代表性自动化用例；记录移动端与桌面回归结果。
