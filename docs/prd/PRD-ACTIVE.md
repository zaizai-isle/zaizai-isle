# Zaizai Isle V1.4.2 执行 PRD

> 版本主题：Built Structures & Living Moments
>
> 状态：Released patch
>
> 基线日期：2026-08-12
>
> 使用对象：产品、设计、前端与 AI Agent

## 1. 背景

Zaizai Isle 是一座持续扩建的个人数字小岛，不是传统简历、作品集、产品官网或信息流平台。V1.3.0 建立了维护记忆；V1.4.0 需要让岛上的构建物更容易被理解，同时容纳新的生活切片，但不把首页变成产品目录。

## 2. 本版目标

唯一主目标：

> 用统一的 Built Structures 关系说明岛内实验与外部作品，并让新结构仍服从小岛叙事。

辅助目标：

- 将项目元数据收敛为可维护的结构注册表。
- 明确稳定、实验中、已归档三类状态。
- 将人生护照与小岛日签作为岛内结构接入首页。
- 保持 Banana 与主岛之间清晰、可返回的归属关系。
- 让发布、文档和运行环境版本保持一致。

## 3. 功能范围

### 3.1 Built Structures

- 使用配置驱动的结构注册表维护标题、描述、类型、状态、链接和更新时间。
- 站内结构在当前标签页打开，站外结构在新标签页打开。
- Works 首屏只呈现精选结构，不增加筛选；活跃结构超过 6 个后再评估筛选。
- Banana 保持实验性结构身份，并提供返回 Zaizai Isle 的路径。

### 3.2 Life Passport

- `/achievement` 以 `Passport v0.1.12` 作为当前内部版本。
- 支持“选择抵达—留下记录—装帧并保存”的三步流程。
- 提供十二类人生主题，并以手绘日期、地点、照片控件完成记录输入。
- 页面和 9:16 导出海报使用一致的本地字体与三类章印语言。
- 当前仅导出纪念卡，不承诺刷新后保存记录。
- 在首页以独立实验结构卡片进入，不取代 Works 的结构注册表职责。

### 3.3 Isle Daily

- `/daily` 以 `Daily v0.1` 作为当前内部版本。
- 首页展示当天日签，并可进入日历查看其他日期。
- 支持中英文内容、四季主题、农历/节气信息和季节预览。
- 内容是安静的时间切片，不发展成资讯流、打卡或运营栏目。

### 3.4 发布与维护

- GitHub Pages 在推送 `main` 后通过 Actions 自动部署。
- 构建与本地项目环境统一使用 Node 25。
- Banana 可通过 Supabase Edge Function 代理 Replicate 图像编辑，私密令牌只存放在服务端 Secret。
- 版本号、变更记录、产品说明和文档地图同步更新到 V1.4.2。

## 4. 非目标

- 不重做首页整体视觉与 12 列 Bento Grid。
- 不建设完整项目索引、CMS 或后台。
- 不为人生护照增加登录、云同步或历史持久化。
- 不把小岛日签做成无限内容流、提醒系统或社交打卡。
- 不以新增卡片数量作为版本成功标准。

## 5. 叙事硬约束

页面继续遵循三层叙事：

1. **System Layer**：状态、事实、边界，低可见度。
2. **Island Layer**：空间、环境、节奏，当前主导层。
3. **Meaning Layer**：极少量方向锚点，全站不超过 3 处。

任何新增结构都必须回答：它在岛上是什么、当前处于什么状态、为何值得被保留。

## 6. 模块职责

- **Identity**：说明正在谁的岛上，不承担系统解释。
- **Core Build**：表达正在形成什么，不展示公开路线图。
- **Built Structures**：呈现被选择保留的构建物，不是作品全集。
- **Life Passport**：记录一次真实抵达的实验工具。
- **Isle Daily**：提供每日一页的时间感，不制造连续使用压力。
- **Archive / Guestbook**：保存访问痕迹，不追求社交活跃度。
- **Weather**：提供环境感知，不承担主叙事。

## 7. 验收标准

- 访客能够区分主岛、站内实验结构和站外结构。
- Built Structures 的状态、类型与链接行为一致。
- 人生护照无照片也能完成并导出；页面明确提示当前不持久化。
- 小岛日签可查看当天和任意日历日期，中英文与四季主题正常。
- 移动端 Banana 顶部导航保持可读并可返回主岛。
- `npm run lint` 与 `npm run build` 通过。
- GitHub Pages 工作流使用 Node 25，并在 `main` 推送后自动发布。
- 文档库不存在仍被列为当前依据的失效链接。

## 8. 误读检查

发布前必须确认：

- 首页没有变成作品集或应用启动器。
- 新文案没有过度解释小岛概念。
- Life Passport 和 Isle Daily 没有争夺主岛身份。
- 视觉与内容增长仍显得克制、可长期维护。

## 9. 发布结论

V1.4.2 完成后，V1.4 继续处于维护状态。下一站是 V1.5 Living State：只通过现有表面表达“岛屿正在生长”，不继续增加首页结构数量。
