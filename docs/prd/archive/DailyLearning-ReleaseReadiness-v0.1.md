## 4. 模式 A 的人工发布门禁

- Agent 可以准备和自动检查内容。
- Agent 不得自行发布、修改已发布内容或购买图片授权。
- `ready` 仅表示自动检查通过，不表示岛主批准。
- 岛主必须明确批准 `content_id` 与 `draft_version`。
- 本轮尚未配置定时任务或正式发布接口。
- 详细规则见 [Agent 内容生产规范](./DailyLearning-AgentProductionPolicy-v0.1.md)。
