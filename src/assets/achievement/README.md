# Achievement UI material sources

These assets are stored locally so the achievement flow does not depend on third-party requests at runtime.

- `paper-fiber.webp` — derived from ambientCG “Paper 001”, released under CC0: https://ambientcg.com/view?id=Paper001
- `watercolor-green.webp` — cropped and optimized from “Watercolor Brushes Paint Stokes” by Karen Arnold, released as CC0 Public Domain: https://www.publicdomainpictures.net/en/view-image.php?image=453680&picture=watercolor-brushes-paint-stokes
- `handdrawn-stroke.svg` — derived from “brush stroke” by Lazur on Openclipart. Openclipart releases its collection under CC0: https://openclipart.org/detail/212674/brush-stroke

The raster derivatives were resized and compressed for UI use. No attribution is required by the licenses, but the sources are retained here for provenance.
